Скалярний добуток векторів

Вітер у спину чи в обличчя? Це скаже одне число. Сьогодні: вітер і перехрестя

Знання

Скалярний добуток за координатами

Теорія
Скалярним добутком векторів a(x1; y1) і b(x2; y2) називають число x1x2 + y1y2:a · b = x1x2 + y1y2

Скалярний добуток — це число, а не вектор.
Позначають: a · b або ab.

Властивості:a · b = b · a(ka) · b = k(a · b)(a + b) · c = a · c + b · c
Скалярний квадрат вектора дорівнює квадрату його модуля:a · a = a² = |a|²За координатами:a² = x1² + y1²

Знання

Скалярний добуток і кут між векторами

Теорія
Кутом між ненульовими векторами a і b називають кут між векторами, що дорівнюють a і b та мають спільний початок.
1) Від точки O відкладаємо OA = a і OB = b.
2) Кут AOB — кут між векторами:
∠(a, b) = φ,
0° ≤ φ ≤ 180°.
Співнапрямлені вектори: ∠(a, b) = 0°.
Протилежно напрямлені: ∠(a, b) = 180°.
Якщо ∠(a, b) = 90°, вектори перпендикулярні: a ⊥ b.
Теорія
Теорема. Скалярний добуток двох векторів дорівнює добутку їх модулів на косинус кута між ними:a · b = |a| · |b| · cos φ
Наслідки (для ненульових векторів a і b):
якщо кут між векторами гострий, то a · b > 0;
якщо вектори перпендикулярні, то a · b = 0;
і навпаки: якщо a · b = 0, то a ⊥ b;
якщо кут між векторами тупий, то a · b < 0.

Кут між векторами за координатами

Теорія
З теореми a · b = |a| · |b| · cos φ для ненульових векторів:cos φ = a · b|a| · |b|
Якщо a(x1; y1) і b(x2; y2), тоcos φ = x1x2 + y1y2x1² + y1² · x2² + y2²
  1. Знаходимо скалярний добуток a · b.
  2. Знаходимо модулі |a| і |b|.
  3. Знаходимо cos φ, а за ним — кут φ (таблиця, калькулятор).
Приклад.
Дано: a(1; −1), b(−1; 0).
Знайти: ∠(a, b).
Розв'язання.
a · b = 1 · (−1) + (−1) · 0 = −1;
|a| = 1² + (−1)² = 2;
|b| = (−1)² + 0² = 1;
cos φ = −12 · 1 = −22;
φ = 135°.
Відповідь: 135°.
